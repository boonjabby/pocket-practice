# Pocket Practice

A phone-friendly, offline-capable companion for real-table blackball practice.

Includes eleven progressive drills, fifteen-shot sessions, position goals, marked cue-ball finishes, variable cut layouts and observation-led shot review. Default setup: an 8-foot table, 2-inch balls and rounded pockets.

## Use

Open the GitHub Pages link in Safari or Chrome and add it to your home screen. Load once online and wait for the offline-ready message under My table before using offline. Scores are saved only in the current device and browser.

## Hosting

Static files, no build step. GitHub Pages publishes from the root of the main branch. All asset paths are relative to support project Pages sites. When assets change, regenerate the service-worker cache version.

## Coaching

The app offers hypotheses based on self-reported observations. It does not analyse video or measure causes. Reference links are included in the app.
